## Final Year Project

This project is my **undergraduate thesis and final year project** at **Sekolah Tinggi Teknologi Terpadu Nurul Fikri (STT-NF), Depok, Indonesia**, where I studied **Informatics Engineering**.

I enrolled in **2022** and graduated in **2026**, completing my degree in **four years on schedule**.

The project focuses on developing a **cloud-based attendance monitoring system** for **Masjid Jami Nurut Taqwa, Depok, Tanah Baru**. The website serves as a platform to receive, manage, and display attendance data sent by a **facial recognition attendance machine** installed at the mosque.

### Tech Stack

* **Frontend:** React, TypeScript
* **Backend:** FastAPI
* **Database:** MySQL
* **Infrastructure:** Docker, Nginx, Caddy
