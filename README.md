## Final Year Project

This project is my **final year project**, focused on developing a cloud-based attendance monitoring system for **Masjid Jami Nurut Taqwa, Depok, Tanah Baru**.

The website serves as a platform to receive, manage, and display attendance data sent by a **facial recognition attendance machine** installed at the mosque.

### Tech Stack

* **Frontend:** React, TypeScript
* **Backend:** FastAPI
* **Database:** MySQL
* **Infrastructure:** Docker, Nginx, Caddy
